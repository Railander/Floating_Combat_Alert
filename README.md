# Floating Combat Alert

A super lightweight World of Warcraft addon that shows floating text when you enter or leave combat.

## Usage

Type `/fca` to open the options window: customize the text, color, font, size and more for each alert, and move or resize the zone the text travels through. While the window is open the alerts preview in a loop; closing it stops the preview. Settings apply instantly, even to text already on screen.

Rapid combat transitions leave several texts floating at once.

If anything ends up lost off screen, `/fca reset` restores the default settings.

## Compatibility

WoW Midnight (12.x).
